1. Install into the target repo (full tree)

From a clone of Coreward:

bash runs/install-into-repo.sh /path/to/your-repo

This copies source, workflows, issue templates, proof viewer, evals, scripts, and the canonical Cursor skill under .cursor/skills/coreward/ (plus a thin vibe-engine alias). It does not overwrite an existing package.json. Instead it writes package.json.vibe-ref as a merge reference.

2. Merge package.json.vibe-ref

Open package.json.vibe-ref and copy the scripts and dependencies you need into your real package.json (Node.js ≥ 22). Until that merge is done, npm run activate and related scripts will not resolve. 

# After install, if package.json was not merged:
# copy scripts/deps from package.json.vibe-ref into package.json
cd /path/to/your-repo
npm install
npm run activate

3. Or use the adopt helper

runs/adopt.sh calls install when needed, then npm install and npm run activate: 

bash runs/adopt.sh /path/to/your-repo
# or, already inside the target after install:
bash runs/adopt.sh .

If only package.json.vibe-ref exists (no merged package.json), adopt prints a warning and will fail at activate until you merge.

4. Enable GitHub Actions

Workflows are copied under .github/workflows/ (forever.yml, vibe-pr-gate.yml, tdd-attribution.yml, vibe-auto-merge.yml, pages.yml). They do nothing useful until Actions is enabled for the repository and any required secrets/variables your org uses are set. Branch protection and required checks are a separate operator step.

Honest limits

  • package.json is not auto-merged — you must integrate package.json.vibe-ref yourself to avoid clobbering an existing app.
  • Actions must be enabled — cloud loop, promotion gate, and Pages deploy require GitHub Actions (and usually permissions for issues/PRs).
  • Not a hosted SaaS — proofs and gates run in your repo; this site documents the primitive.
  • Posture packs ≠ law — legal-space dials are optional configuration, not compliance certification.
  • CyberReady — Planned only; see Status. Missing bridge fails open; it does not block the vibe path.
