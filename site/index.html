Coreward

A portable promotion gate for agent-authored changes: sealed work orders, optional Mandate–Ward session budgets, adversarial gauntlet, tamper-evident receipts, and deterministic replay—free to run in your own repository.

Mandate = signed session contract (budget); Ward = CI/promote ALLOW/DENY when a Mandate is on; AgentId = portable actor profile. Receipts never authorize. IDE Edit/Shell can still bypass Ward.
