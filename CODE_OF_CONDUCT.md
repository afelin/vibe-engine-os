# Code of Conduct

## Our pledge

We pledge to make participation in Coreward a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, experience level, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Standards

**Expected:** respectful disagreement, claim-safe technical critique, assuming good faith.

**Unacceptable:** harassment, personal attacks, doxxing, publishing others’ private information, or using the project spaces to push unrelated commercial spam.

## Enforcement

Report concerns privately to the repository maintainer via GitHub (Security Advisories for security; otherwise a private contact on the maintainer profile). The maintainer may warn, moderate, or ban as appropriate.
