# vibe-engine-os — project blurb (RI.SE paste)

vibe-engine-os is a free, portable open-source promotion gate for AI-assisted software change. Generative tools may propose edits; house rules—task bonds, house mandates, zero-token release gates, and a depth dial—decide what may land in Git. An optional signed **Mandate** (session contract) enables engine-path **Ward** checks on CI/promote when present; receipts never authorize, and IDE Edit/Shell can still bypass Ward. Each governed run can leave a tamper-evident capsule fingerprint, an HPURL proof link, and a replayable event log so operators and auditors can inspect what was sealed, not merely trust a chat transcript. An adversarial gauntlet and Assisted-by attribution checks help keep refusal behavior and authorship labeling mechanical rather than aspirational. Optional posture packs overlay repository house rules only; they are not encodings of NIS2, CRA, or other law. An optional CyberReady bridge is Planned and fail-opens when absent—it does not block promotion. Operators adopt the primitives into an existing repository with `runs/adopt.sh`, activate vows and schemas locally, and run the forever loop on their own GitHub Actions. This description makes no certification claims and does not describe paid product tiers.
